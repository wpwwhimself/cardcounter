# Wprowadzenie

Reguły stosów są określane poprzez nadanie dodatkowych klas stosom (tj. divom `.card-tray`). Są one sprawdzane po wykonaniu określonych operacji.

# Zasady porządkowania

Domyślnie stosy są rozkładane szeroko, tzn. tak, aby widoczne były wszystkie karty na stosie.

## compact

Sprawia, że stos wyświetla tylko najwyższą kartę na stosie.
